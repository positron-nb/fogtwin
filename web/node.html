The prototype board, live

This page shows one small piece of hardware on a desk: an ESP32 with a motion sensor and a distance sensor, reporting over Wi-Fi. Everything below is measured by that board right now. Nothing here is simulated, and nothing is drawn from anywhere else in the system.

Nothing is reporting yet

The board is not sending anything, so the panels below are empty rather than filled in with something invented.

Power the ESP32 and let it join Wi-Fi, or run the desktop stand-in: python firmware/rover_desktop.py --twin http://localhost:8000
